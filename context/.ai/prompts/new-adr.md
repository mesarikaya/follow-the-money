# Prompt: New Decision

Use when making a significant architectural or technology decision.

---

```
Add a new decision to DECISIONS.md for the following: [DESCRIBE DECISION]

Add it under "Accepted decisions" with this structure:

### D-XXX — [Title]

**Status:** Proposed · **Date:** YYYY-MM-DD

[One paragraph: what we decided and why.]

**Why [rejected alternative] was rejected:** ...

**Upgrade path:** If we ever need [more complex alternative], [how to add it].

---

After drafting, present to user for review first (status: Proposed).
On confirmation, change to: Accepted.
Then: update affected sections in spec.md, append to CHANGELOG.md.
```
