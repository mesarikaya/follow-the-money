# Prompt: New Sprint Plan

Use when starting a focused work sprint on one or more epics.

---

```
Create a sprint plan for the following work: [DESCRIBE FOCUS]

File: plans/sprint-NN-[milestone]-[short-title].md

Use this structure:

# Sprint NN — [Title]

**Date:** YYYY-MM-DD  
**Milestone:** MX  
**Epics in scope:** EP-XXX, EP-XXX

## Goal
What will be true at the end of this sprint that isn't true now?

## Tasks

### Day 1
- [ ] T-XXX-1: [description]
- [ ] T-XXX-2: [description]

### Day 2
...

## Out of scope this sprint
- [Item] — deferred to sprint NN+1

## Risks
- [Risk] — mitigation: [...]

## End state / demo criteria
How will we verify the sprint goal was achieved?
```
